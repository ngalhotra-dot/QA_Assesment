# Restful Booker API Automation

API automation test suite for the Restful Booker API using Playwright and TypeScript.

## Objective

This project demonstrates API test automation covering:

- Authentication
- Booking creation
- Dynamic booking ID handling
- Booking retrieval
- Booking update
- Updated booking validation
- Booking deletion
- Deletion verification
- Negative scenarios
-

---

## Technology Stack

- Playwright
- TypeScript
- Node.js
- Playwright APIRequestContext
- Git
- GitHub
